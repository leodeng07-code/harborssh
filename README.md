# Harbor SSH

一个面向 Windows 的中文桌面 SSH 工具，提供批量连接、交互终端、SFTP 文件传输、SSH 隧道和 SNMP v2c 网络设备管理。所有配置在本机保存，无需账号和云服务。

## 在 Windows 使用

适用目标：Windows 10 / 11，x64。

- 安装版：运行 `HarborSSH-0.5.5-setup-x64.exe`，按向导选择安装目录。
- 免安装版：将 `HarborSSH-0.5.5-windows-x64.zip` **完整解压**到一个文件夹，再运行 `Harbor SSH.exe`。请保留所有 DLL、resources 和其他随附文件。
- 首次运行为空连接库，可以点击“新建连接”或“导入 Excel”。
- 这是未签名的测试版。Windows 可能显示发布者验证提示；请先确认文件来源和随附 SHA256 校验值。

程序内已包含 Electron 运行环境，最终用户无需安装 Node.js、Python、OpenSSH 或其他开发工具。使用 SSH Agent 时需要自行启用系统的 OpenSSH Authentication Agent 服务。

## 当前功能

- SSH 密码、OpenSSH / PEM 私钥、加密私钥口令及 SSH Agent 认证。
- 多标签交互终端，UTF-8、颜色、终端尺寸同步、鼠标选中自动复制、右键粘贴、滚动历史与搜索。
- Linux 运行状态侧栏：CPU 使用率与趋势、负载、内存与 Swap、磁盘、逐网卡收发速率和运行时间，自动识别并定时刷新。
- 三级主机分组（设备类型 → 地点 → 网络类型）、收藏、搜索、卡片 / 列表视图、批量打开连接和批量删除。
- 批量执行命令，并发数量 1–20，超时 5–3600 秒；逐台展示输出、退出码和耗时，支持停止任务和复制结果。
- SFTP 远程文件面板，与终端并排使用：文件和文件夹的批量上传下载、流式进度、取消、目录导航、新建目录、重命名、删除文件或空目录。
- SNMP v2c 接口状态、描述、速率、双工与 PVID 查看；接口启停、描述与 PVID 修改；按设备适配 VLAN 模式、速率、双工的可写 MIB 参数；MAC 查端口、LLDP 邻居查询。
- 本地转发 `-L`、远程转发 `-R` 和动态 SOCKS5 转发 `-D`；独立启停、错误反馈和连接次数。
- Excel `.xlsx`、UTF-8 `.csv` 批量导入、逐行校验和重复识别；可下载模板、导出连接列表。
- 首次连接核对 SHA256 主机指纹，已信任主机指纹变化时阻止连接。
- 软件密码登录：首次设置，之后每次启动输入密码解锁；SSH 密码和私钥口令自动加密保存，退出后保留，编辑窗口留空保留原密码。
- 7 套界面与终端主题：深海绿、极夜蓝、暮色紫、石墨灰、暖沙棕、晴空白、布布一二；设置在本机保留。

## 终端鼠标与显示

终端内用左键拖动选择文字，松开后自动复制；双击选择单词也会复制。右键粘贴系统剪贴板到当前已连接的终端，支持 Ctrl+C 复制选区、Ctrl+V 粘贴，也兼容 Ctrl+Shift+C/V；无选区时 Ctrl+C 仍可中断命令。显式复制或粘贴完成后清除旧选区，鼠标选中自动复制保留选区供核对。单击或空选区不会清空剪贴板；右键只在终端区域生效。粘贴遵循远端 bracketed-paste 模式，不额外添加回车；剪贴板原有的换行仍会保留。远端程序接管鼠标（如 tmux/vim）时，按住 Shift 可强制选择文本。

SSH 会话断开或连接失败后，聚焦终端按 R 可重新连接；连接正常时 R 仍输入普通字符。

SSH 页直接显示终端标签及内容，打开连接移到顶部工具栏，省去大标题和介绍区。布布一二主题使用半透明选区与高对比文字，粘贴时移除旧选区。

连接卡片和列表完整换行显示设备名称；默认界面基准字号 15px，常用辅助文字约 14px。在“偏好设置 → 界面字号”可选择 14、15、16 或 18px；与独立的终端字号设置分别保留，默认终端字号 16px。

## Linux 运行状态

当前可见的 SSH 会话连接成功后，通过独立的 SSH exec 通道执行一次 `uname -s` 识别系统；识别为 Linux 后自动展开右侧运行状态，无需安装代理或额外输入密码。顶部“状态”按钮可展开、收起；“状态”和 SFTP“文件”面板切换显示，文件传输可继续在后台进行。

面板展示主机名、发行版、内核、运行时间、CPU 使用率与最近采样趋势、1/5/15 分钟负载、内存与 Swap、本地文件系统挂载点及逐网卡收发速率。内存优先使用 MemAvailable，旧内核回退估算会标注；CPU 和速率由两次有效采样的差值计算，首次显示“采样中”，计数重置或重启后重新取基线，不用 0 伪装未知值。网卡分别显示，不汇总虚拟接口以避免重复计数。

默认每 5 秒刷新；可暂停、继续和手动刷新。切换页面、会话、收起状态、显示 SFTP 或应用进入后台后暂停轮询。断开后保留最后数据并明确标记，连续 3 次失败后暂停，点击刷新可重试。非 Linux 或拒绝 exec 的设备不会自动展开；手动打开时显示不支持提示，普通终端仍可使用。

查询使用当前账号权限，只读 `/proc`、`/etc/os-release` 和 `df`，不使用 sudo，不向交互终端输入命令，也不将状态查询写入终端会话日志。服务器须允许 SSH exec 通道，提供常用 Linux 工具和可读的 `/proc`；受限账号、容器、缺少命令或文件系统超时可能使部分指标不可用。容器中显示的是账号能看到的指标，未按 cgroup 配额修正。当前不包含进程管理、告警或长期监控历史。

指标定义参考 [Linux 内核 /proc 文档](https://docs.kernel.org/filesystems/proc.html)。

## Excel 批量导入

点击“下载导入模板”，或使用随附的 `SSH导入模板.xlsx`。在 **连接列表** 工作表第一行表头下填写连接，第二个工作表提供字段说明。也能读取英文表头。

| 字段 | 说明 |
| --- | --- |
| 连接名称 / name | 可选，留空使用主机地址 |
| 主机地址 / host | 必填，IP 或域名，不包含 `ssh://` 与端口 |
| 端口 / port | 默认为 22，范围 1–65535 |
| 用户名 / username | 必填 |
| 认证方式 / authType | `password`、`key`、`agent`，或“密码”“私钥”；留空时有私钥路径则使用私钥，否则使用密码 |
| 密码 / password | 密码认证的登录密码 |
| 私钥路径 / privateKeyPath | 使用私钥认证时必填，须指向运行程序的 Windows 电脑上的文件 |
| 私钥口令 / passphrase | 私钥加密口令，可选 |
| 设备类型 / deviceType | 一级分组，可选；例如交换机、防火墙、服务器 |
| 地点 / location | 二级分组，可选；例如上海、北京 |
| 网络类型 / networkType | 三级分组，可选；例如办公网、生产网、管理网 |
| 分组 / group | 兼容旧表，可填完整路径，例如 `交换机 / 上海 / 办公网`；与三级字段同时填写时必须一致 |
| Agent 路径 / agentPath | 可选，留空使用系统 Agent |

每次最多 2000 条、文件不超过 10 MB；解压后的内容不超过 64 MB。按“地址 + 端口 + 用户名”识别重复，预览时跳过已有凭据的现有连接和文件内重复记录。若现有连接缺少凭据，可勾选“为重复连接补充缺失凭据”，保留原连接名称、三级分组与设置，不覆盖已有凭据。密码前后的空格会保留。密码列请设置为 **文本** 格式，避免 Excel 丢失前导零。导入不执行公式，公式单元格会报错。旧版 `.xls` 请先另存为 `.xlsx`。

密码列可以留空以先建立连接配置，实际连接前再编辑填写密码。导入凭据自动使用软件密码保护并加密保存，退出后仍然有效。Excel 源文件里的密码仍是明文，请妥善保管。

导出 Excel 不包含密码、私钥口令或私钥内容。导出的私钥路径属于当前电脑，在另一台电脑使用前需要修改。导出仅含连接列表，不包含隧道配置和主机指纹。

## 三级分组

支持最多三级：**设备类型 → 地点 → 网络类型**。例如：

```text
交换机
├─ 上海
│  ├─ 办公网
│  └─ 生产网
└─ 北京
   └─ 办公网
防火墙
└─ 上海
   └─ 管理网
```

左侧目录可展开和折叠。点击任一级，会显示该分组及所有下级的主机；计数同样包含下级主机。可全选当前列表后批量连接、执行命令或删除。批量删除确认框会列出所有选中主机（包括其他分组中仍选中的主机）、会话与关联隧道数量；确认后删除连接、凭据及其隧道配置，关闭相关会话与隧道。正在执行批量任务的连接须先停止任务。在选中分组中新建连接会自动带入分组路径。搜索支持按任一级名称查找。

新建或编辑连接时，分别填写三个字段，也可只填一级、前两级，或全部留空作为“未分组”。不能跳过设备类型或地点直接填写下级。每级名称最多 80 个字符。旧版一级分组升级后保留为一级，不会根据名称中的斜杠自动拆分。新模板和导出表使用三列保存层级；旧表“分组”列中的 `/` 用作路径分隔符。

## SFTP 文件传输

连接主机后，在终端右上角点击 **文件**，打开并排的远程文件面板。拖动中间的分隔条可调整宽度，收起文件面板后传输仍会继续。每个终端标签拥有自己的远程目录与传输记录。SFTP 优先复用当前 SSH 连接；遇到 `Channel open failure` 时自动尝试独立 SSH 连接并重新验证主机指纹，使用当前连接的主机与账号及已保存的凭据，不切换到编辑后的其他主机。兼容模式下目录与传输共用一个 SFTP 通道，取消单项任务不会结束其他任务或交互终端；关闭终端会关闭独立文件连接。普通 Linux/OpenSSH 服务器继续使用原连接与独立传输子通道。

SSH 能登录不代表 SFTP 已开放。交换机需启用 SFTP 服务、允许当前账号访问且设置可访问的工作目录；设备的 SSH/SFTP 在线用户数限制也可能拒绝连接。若独立连接仍失败，面板会给出错误，不会自动重发文件写入或改用 FTP/TFTP。部分交换机不支持 OpenSSH 安全覆盖扩展，上传新名称通常可用，覆盖现有文件仍会明确报错并保留原文件。

- 点击文件夹进入，或在路径栏输入远程路径并回车；支持上级目录、主目录、刷新和当前目录筛选。
- 点击“上传文件”可多选本机文件；旁边的文件夹上传按钮可选择整个文件夹。
- 勾选远程文件或文件夹后点击“下载”，选择本机保存目录。文件夹递归复制并保留空目录。
- 默认不覆盖同名文件；需要覆盖时先勾选“覆盖同名文件”。上传覆盖使用 OpenSSH 的 POSIX rename 扩展，服务器不支持或没有权限时会报错并保留原文件。下载提交使用目标目录内临时文件；未勾选覆盖时使用排他硬链接提交，目标文件系统需支持硬链接（例如 NTFS）。
- 可新建远程文件夹、重命名项目、确认删除文件或空目录。非空目录不递归删除，权限取决于 SSH 登录用户；这些操作不通过 Shell 拼接命令。

传输队列显示方向、字节数、文件数与状态，可逐项取消；同时执行 2 项、最多排队 100 项，保留最近约 200 项记录。文件夹最多 32 层、10000 个条目；不跟随符号链接或复制设备文件。无法用于 Windows 的名称以及同目录中仅大小写不同的文件会明确报错，请先在远程重命名。

文件以流方式传输，以 128 KB 分块读写，先写入 `.harbor-*.part` 临时文件，成功后提交。取消时清理当前临时文件，已经完成的文件和目录会保留；网络断开或权限变化时可能留下临时文件，可重连后检查清理。传输不支持断点续传、权限编辑或保留所有者及时间戳。新上传文件默认权限 600，新目录默认 755。关闭终端会取消其传输，操作前会提示；退出程序会停止全部传输。服务器须开启 SFTP 子系统，账号需要相应目录的读写权限。

## 批量执行结果判定

命令退出码与 SSH 连接状态分开处理。退出码 `0` 显示“成功”，非零退出码或退出信号显示“失败”。收到退出码后再发生连接中断，会保留命令结果并提示核对输出完整性。缺少退出码而已有输出、或通道正常关闭却没有退出码，显示“已返回 · 待确认”，单独计数，不计入成功或失败。认证失败、无输出的传输错误、执行超时仍显示失败。

例如华为/H3C 设备在返回 CLI 输出及提示符后重置连接，可能产生 `read ECONNRESET`。这只能说明 SSH 连接被重置，无法据此断定 CLI 命令失败或全部成功。请核对实际输出，配置命令未确认时避免直接重复下发。程序不会自动重试命令，也不凭“有输出”猜测成功。

## SNMP v2c 网络管理

在左侧点击“网络管理”（Ctrl+5），用搜索框按名称、IP、地点或分组查找设备（支持多个关键词同时匹配），在结果中点击或按 ↑↓、Enter 明确选择目标。可勾选“仅已配置 SNMP”；Ctrl+K 聚焦网管搜索，左侧搜索也会留在网管页筛选设备。搜索不自动切换目标，不会触发 SNMP 请求；当前目标名称、地址与分组独立展示，重返页面及重启后保留上次选择。在“SNMP 配置”中设置 UDP 端口（默认 161）、只读 Community；需要修改时再单独设置读写 Community。Community 使用软件密码保护的凭据库加密保留，不在接口或编辑窗口回显；留空保留已有值，勾选“移除已存读写 Community”可以恢复只读。SSH 登录凭据与 SNMP 凭据独立，SNMP 请求直接通过 UDP 发往设备，不经过 SSH 隧道。v2c Community 在网络上明文传输，宜用于受控管理网。

“读取接口”通过标准 IF-MIB、EtherLike-MIB、BRIDGE-MIB、Q-BRIDGE-MIB 获取接口名称、ifIndex、管理/链路状态、当前速率、双工、描述、MAC 和 PVID。某个对象不支持、权限不足或超时会列出未获取项，不能据此判断设备没有该配置。不会进行后台轮询。

点击接口行“修改”，可选端口启用/停用、描述、PVID、VLAN 模式、速率配置或双工配置。提交后需核对原生确认窗口中的设备、接口索引及新旧值。程序重新读取当前值防止覆盖并发修改；SET 不自动重试，完成后回读验证。SET 超时、未确认响应或回读失败会明确提示先刷新核对，不报告已验证成功。停用端口或修改 VLAN/速率可能中断业务和管理连接。SNMP SET 是否写入设备的启动配置取决于设备实现，本版不代替设备的保存配置流程。

标准 PVID 使用 `dot1qPvid`（Unsigned32），先将 ifIndex 映射到桥端口再读写，范围 1–4094。PVID 只是端口默认 VLAN，不是 Trunk 放行列表，也不会自动创建 VLAN。VLAN 模式、速率、双工的配置因厂商/型号而异，须在“MIB 适配”中填写该设备**可写的数字列 OID、ifIndex 或 bridgePort 索引、ASN.1 类型及枚举值**。支持 Integer、Unsigned32、OctetString、OID，枚举每行填写 `显示名称=实际值`。适配仅绑定当前设备，不会自动传播给其他型号；无适配或对象未读取成功时禁止修改。

设备清单中的 `sysObjectID` 用于识别型号，不能替代上述配置参数。`ifSpeed` 和 `dot3StatsDuplexStatus` 是只读状态，不能直接用于写入配置。本版提供参数适配入口，尚未预装华为/H3C 各型号的私有可写映射；需要厂商 MIB 定义或经过验证的参数表。Trunk VLAN 位图、VLAN 创建/删除及复杂多表事务仍需按具体设备另行适配。

“MAC 查端口”在**当前设备**查找 Q-BRIDGE 与 BRIDGE 转发表，按桥端口映射到 ifIndex/接口名称；Q-BRIDGE 的 FDB ID 通过 VLAN 表转换为 VLAN ID，二者不会直接混用。显示动态学习、静态管理等条目类型，过滤无效条目；不支持/访问失败与未命中会分别提示。结果可能为上联口或聚合口，仍需到下级设备继续查找，尚未自动跨设备追踪。条目可能因老化、设备未学习或 VLAN 视图限制而查不到。每次操作最多 45 秒，每张表最多 100000 条，超限明确提示结果不完整。

标准参考：[IF-MIB（RFC 2863）](https://www.rfc-editor.org/rfc/rfc2863.html)、[BRIDGE-MIB（RFC 4188）](https://www.rfc-editor.org/rfc/rfc4188.html)、[Q-BRIDGE-MIB（RFC 4363）](https://www.rfc-editor.org/rfc/rfc4363.html)。

### LLDP 邻居

网络管理使用“设备接口 / LLDP 邻居 / MAC 查端口”标签切换，设备选择与配置共用顶部区域，数据表占据余下空间。LLDP 页面点击“查询 LLDP”读取当前设备的标准 LLDP-MIB，无需本地 MIB 文件或 SSH 会话。展示本地端口标识、对端系统名、机箱标识、对端端口、IPv4/IPv6 管理地址和设备能力，并可按端口、名称或地址筛选。查询使用只读 Community，不会开启或修改设备 LLDP。

邻居通过完整的 TimeMark、本地端口号和邻居索引区分，同一端口多邻居不会合并；管理地址按完整索引关联。LLDP 本地端口号不直接等同于 ifIndex。未通告的名称或管理地址显示为未返回；未返回 LLDP-MIB 与可读取但未返回邻居分别提示，不能据此断定物理网络没有邻居。适用于开放标准 LLDP-MIB 的设备；尚未实现 LLDP-V2 私有适配、跨设备自动拓扑追踪或 CDP。

对象与索引定义参考 [H3C 官方 LLDP-MIB 文档](https://www.h3c.com/cn/d_202504/2413129_30005_0.htm)。

### 没有 MIB 文件时

使用本软件内置的标准数字 OID，不需要额外加载 MIB 文件。接口查看、MAC 查端口，以及设备允许的标准接口启停、描述和 PVID 修改仍可使用，具体由设备支持情况和 SNMP 访问权限决定。厂商私有配置也不一定需要本地文件，只要能从对应型号/软件版本的官方文档核实列 OID、索引、类型及枚举值，即可填写 MIB 适配。

华为可以使用 [Info-Finder 官方 MIB 查询](https://info.support.huawei.com/info-finder/tool/zh/enterprise/mib) 按型号与版本查找。部分 H3C 设备支持 `display snmp-agent mib-node verbose` 查看节点 OID、类型及读写属性，`display snmp-agent mib-node index-node` 查看索引；应以当前型号和版本的[官方命令手册](https://www.h3c.com/en/d_202309/1930195_294551_0.htm)为准。完整输出可能较长，按需采集，注意软件的批量输出长度上限。不能根据 SNMP GET 的返回值反推一个对象是否可写，也不能仅凭一次 walk 确定写入枚举语义。

## SSH 隧道示例

- **本地转发**：本机监听 `127.0.0.1:13306`，目标 `127.0.0.1:3306`，SSH 连接选择数据库所在的服务器。连接本机 `13306` 即可访问服务器侧 MySQL。
- **远程转发**：服务器监听 `127.0.0.1:18080`，目标 `127.0.0.1:3000`。服务器连接 `18080` 时，流量会转到运行本工具电脑上的 `3000`。
- **SOCKS5**：本机监听 `127.0.0.1:1080`，应用的代理设置为 SOCKS5；使用 `socks5h://127.0.0.1:1080` 时，由 SSH 服务器解析目标域名。

每条隧道使用独立的 SSH 连接，关闭终端标签不会关闭隧道。退出程序会停止所有隧道。默认只监听本机回环地址。SOCKS5 不提供用户名密码认证，仅支持 TCP CONNECT，不支持 UDP / BIND。远程监听范围受 SSH 服务器 `AllowTcpForwarding`、`GatewayPorts` 等配置限制。

## 自动终端日志

每次 SSH 连接自动创建独立日志，持续将远端终端输出写入磁盘，不依赖 2MB 的终端历史缓冲。默认保存至应用用户数据目录的 `logs` 子目录，可在“偏好设置 → 终端日志自动保存 → 选择保存目录”更改，并可直接打开目录。选择目录会检查写入权限；修改从新会话生效，正在记录的会话继续写入原目录。

连接期间文件名为 `连接名称_连接中_开始时间_会话ID.recording.log`；手动断开、远端断开、连接失败或正常退出软件后，写完尾部、同步并关闭文件，改为 `连接名称_断开时间_会话ID.log`。时间使用运行电脑的本地时间，精确到毫秒。连接名称会替换 Windows 文件名非法字符、处理保留名并限制长度，会话ID避免并发连接同名覆盖。文件内容保留原始终端输出（含颜色和光标控制序列），开头和结尾包含时间与结束原因。

异常结束进程或停电时，已写入的 `.recording.log` 保留，不能获得尚未发生的断开时间。软件正常退出会等待日志完成；日志写入失败会显示明确提示，已写入内容保留，不会清理原有文件。日志为明文，包含远端回显；不会另行记录键盘输入或保存 SSH 登录密码。日志不自动删除，需自行管理磁盘空间。SFTP 文件内容、隧道数据、批量执行输出不属于交互终端日志。

## 数据与凭据

Windows 配置通常位于 `%APPDATA%\harborssh\config.json`。免安装版同样使用用户配置目录。配置包含主机信息、隧道和信任指纹；凭据仅以密文写入。私钥只保存路径，在连接时读取，不复制到配置文件。

首次启动时设置至少 8 个字符的软件密码，之后每次启动输入它来解锁。SSH 密码和私钥口令使用 AES-256-GCM 加密，软件密码经 scrypt（N=32768, r=8, p=1）派生密钥，用于加密随机数据密钥。随机盐和加密后的数据密钥保存在同目录的 `vault.json`。在“偏好设置 → 凭据与本地数据”中可修改软件密码，无须重新输入所有 SSH 密码。

请牢记软件密码；程序没有找回密码或解密后门，忘记后无法恢复加密凭据。备份或迁移时请同时保留 `config.json` 与 `vault.json`，建议备份整个用户配置目录。主机名称、地址、分组与隧道配置属于明文元数据；软件密码保护登录与凭据，不会隐藏磁盘上的这些元数据。已解锁的运行中进程需要使用明文凭据，软件密码不防御同一用户权限下对该进程的攻击。

从旧版升级时，已有系统加密凭据会在本机解锁后尽可能迁移。旧版未勾选保存而已在退出时丢失的密码无法恢复：重新导入原 Excel，勾选“为重复连接补充缺失凭据”，或编辑连接重新填写即可。新版本已取消临时凭据模式，不再因退出而清除密码。

服务端密钥变化时，请向管理员核对。确认后在编辑连接中点击“重置信任指纹”，再次连接时重新核对。批量执行结果仅在当前程序内保留，最多保留最近 10 次任务；单台输出约 128 KB、单次任务总输出约 8 MB，超出后截断。停止批量任务会关闭 SSH 通道，远程进程是否终止还取决于服务器及命令本身。

## 开发与构建

Node.js 22.12 或以上，建议使用 Node.js 24。在项目目录运行：

```sh
npm ci
npm run dev
```

如果包管理器提示 Electron 安装脚本被阻止，按该包管理器的机制允许 `electron` 的安装脚本；Electron 需要下载对应操作系统的运行环境。

```sh
npm run check        # TypeScript 检查
npm test             # SSH / 隧道 / 配置 / Excel / 分组集成检查
npm run build        # 生产前端与 Electron 代码
npm run test:ui      # Electron 界面冒烟检查，需要图形桌面
npm run test:sftp    # SFTP 真协议、终端并行、上传下载、目录操作、取消和布局
npm run test:network # 本机 SNMP v2c / Electron：凭据、接口、MIB 适配、SET 回读、MAC 与批量状态
npm run test:security # 软件密码、退出重开、主题、凭据恢复及批量删除
npm run test:desktop # 本机 SSH + Electron + Excel 完整流程，需要图形桌面
npm run dist:win     # 生成 x64 Windows NSIS 安装包与 ZIP
```

构建输出在 `release/`。跨平台生成的 Windows 包已完成构建与内容检查；Windows 安装和 SSH Agent 的真实运行仍需在 Windows 电脑验收。Linux 测试使用 SSH2 协议测试服务，覆盖终端输入、密码与私钥认证、主机指纹拒绝、命令执行、三种隧道、端口释放、取消和超时；不代表已经在所有实际 SSH 服务端验证。

前端使用 React / xterm.js，Electron 主进程通过 ssh2 建立真实连接，net-snmp 提供 SNMP v2c 请求，ExcelJS 负责导入导出。SNMP 已通过本机真实 UDP 协议代理测试；未连接用户现场设备，不代表全部私有 MIB 已验证。界面沙箱与上下文隔离开启，仅通过受限 IPC 暴露功能，并校验消息来源和输入。

当前版本暂未包含跳板机、交互式 MFA、PuTTY PPK 原生支持、自动重连、开机自启和云同步。批量任务是非交互式执行，不支持在中途输入 sudo 密码。终端标签上限为 100 个。
